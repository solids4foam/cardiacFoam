# Simulation Runs

Contains the active `cardiacFoam` run folders. These are automatically populated from the templates and meshes by the setup scripts in `scripts/`.
The cases compare:

- **Polyhedral Dual Meshes**: `monodomain_coarse`, `monodomain_medium`, `monodomain_fine`
- **Tetrahedral Origin Meshes**: `monodomain_coarse_tet`, `monodomain_medium_tet`, `monodomain_fine_tet`
