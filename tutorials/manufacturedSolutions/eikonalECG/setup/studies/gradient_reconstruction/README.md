# gradient_reconstruction - eikonalECG

## Purpose
This study evaluates different numerical gradient schemes (e.g., Gauss linear, leastSquares) and their impact on eikonalECG simulation metrics.

## Execution
Run the custom bash script (e.g., `./run_gradient_scheme_screen.sh` or `./run.sh`) to evaluate scheme configurations.

## Tracking & Outputs
All generated outputs, mesh files, and metric archives are saved to the local `results/` folder, which is explicitly ignored by git. Do not commit generated OpenFOAM data.
