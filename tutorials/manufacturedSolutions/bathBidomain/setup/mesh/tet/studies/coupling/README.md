# coupling - bathBidomain

## Purpose

This study analyzes decoupled vs. coupled interface physics and mesh conformal configurations for bathBidomain.

## Execution

Run `./run_coupling_study.sh` and parse metrics with `./summarize_coupling_study.py`.

## Tracking & Outputs

All generated outputs, mesh files, and metric archives are saved to the local `results/` folder, which is explicitly ignored by git. Do not commit generated OpenFOAM data.
