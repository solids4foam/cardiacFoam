# manufacturedSolutions/bathBidomain tutorial

This tutorial is the FDA bidomain-with-bath manufactured-solution setup.

## Stack

- myocardium solver: `bidomainSolver`
- ionic model: `bidomainFDAManufactured`
- myocardium verifier: `manufacturedFDABathBidomainVerifier`
- potential domain: `extracellularPotentialDomain`
- bath ECG solver: `bathECGProbe`
- bath ECG verifier: `bathECGManufacturedVerifier`
- pseudo ECG solver: `pseudoECG`

## Mesh Layout

The case uses one base mesh over `[-1,2]` with two cellZones:

- `myocardium`: `0 <= x <= 1`
- `bath`: `-1 <= x <= 0` and `1 <= x <= 2`

`topoSet` creates the zones after `blockMesh`. The
`extracellularPotentialDomain` solves the global `phiE` equation on this unified
mesh and binds that field back into the bidomain solver. The ECG stage only
samples the already-solved global `phiE` with `bodyECG`/`bathECGProbe`, and
computes myocardium-derived pseudoECG with `pseudoECGSignals`/`pseudoECG`. It
does not own a separate bath PDE.

## Manufactured Parameters

The shared dictionary is:

```foam
manufacturedBidomain
{
    k               0.7071067811865476;
    alpha           0.01;
    groundElectrode yes;
}
```

The bath conductivity field is generated by
`setTorsoOrganConductivityField` as `bodyAndOrgansConductivity`.

The ECG-side manufactured verifier currently accepts only the FDA grounded
variant used here: `phiE = 0` on `xMin` and `+alpha` surface current on `xMax`.

## Execution

Manual 1D smoke run:

```bash
blockMesh -dict system/blockMeshDict.1D
./Allrun
./runRegressionTest.sh
```

Typical outputs include global `phiE`, `bathECG.dat`, `pseudoECG.dat`,
`manufacturedBathECG.dat`, and manufactured error summaries in `postProcessing/`.
