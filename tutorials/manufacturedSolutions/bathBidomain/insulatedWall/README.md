# bathBidomain/insulatedWall

2D rotated-anisotropy bath-bidomain manufactured solution with a conormally
insulated heart/bath interface.

Origin: this work. The parent case is the bidomain-with-bath problem of the FDA
regulatory science tool (Pathmanathan & Gray 2014).

## Overview

### Purpose

The parent case `bathBidomain` is 1D with diagonal conductivity
tensors, so it cannot distinguish a sealed heart/bath interface that imposes
`n.grad(phiE) = 0` from the correct conormal condition
`n.(G_i grad(phiI)) = 0`: the two coincide when the tensors are diagonal and
the solution only varies along the interface normal. This case uses a
rotated, fully populated intracellular tensor and a periodic-in-y exact
solution with `n.(G_i grad(phiI)) = 0` at the heart/bath interfaces but
`n.grad(Vm) != 0` and `dVm/dy != 0` there, so a solver that discretises the
wrong boundary condition fails to converge.

### Stack

- myocardium solver: `bidomainSolver`
- ionic model: `bidomainFDAManufactured`
- myocardium verifier: `manufacturedConormalBathBidomainVerifier`
- bath potential domain: `bidomainSolverCoeffs.bathPotentialDomain`
- sealed heart boundary: `sealedHeartBoundary true`, `bathHeartPhiETrace global`,
  `sealedWallTrace conormal`
- heart/bath interface: `interfaceConductivityInterpolation conormalHarmonic`
- complete time coupling: explicit first-order `godunov` (Lie splitting)

### Mesh Layout

The mesh covers `[-1,2] x [0,1] x [0,0.05]` with two cellZones:

- `myocardium`: `0 <= x <= 1`
- `bath`: `-1 <= x <= 0` and `1 <= x <= 2`

`y` is periodic (`y0`/`y1` cyclic patch pair across all three blocks); `x = -1`
and `x = 2` are insulated (`patch`) walls with no electrodes; `z` is a single
`empty` cell. `system/blockMeshDict` reads its cell count per unit length from
the `N` entry.

### Manufactured Parameters

```foam
conductivityIntracellular [ -1 -3 3 0 0 2 0 ] ( 0.09878815375 0.0394860234186752 0 0.05319362125 0 0.030396355 );
conductivityExtracellular [ -1 -3 3 0 0 2 0 ] ( 0.0409193930850485 0.0163556464241969 0 0.0220335193534877 0 0.0125905824877072 );
verificationModel
{
    type            manufacturedConormalBathBidomainVerifier;
    k               0.70710678118654746;
}
```

`conductivityIntracellular` is `R(pi/6) diag(0.121585420, 0.030396355) R(pi/6)^T`
in the `xy` block with `zz = 0.030396355`; `conductivityExtracellular = kappa
conductivityIntracellular` with `kappa = sqrt(2) - 1`. Bath conductivity is
uniform `0.0230827345`, generated by `setTorsoOrganConductivityField` as
`bodyAndOrgansConductivity`.

The exact solution solves a linear system for the heart's homogeneous
conormal-null mode and the two bath `cosh` amplitudes once, at verifier
construction (`manufacturedConormalBathBidomainReference.H`); see that header
for the closed form.

## Usage

```bash
./Allrun
./regression/regressionTest.sh
```

To change the cell count per unit length from the committed `N=20`, replace
the `blocks` entry directly, e.g.

```bash
foamDictionary -precision 17 -entry blocks -set \
  '(hex (0 1 5 4 8 9 13 12) (10 10 1) simpleGrading (1 1 1) hex (1 2 6 5 9 10 14 13) (10 10 1) simpleGrading (1 1 1) hex (2 3 7 6 10 11 15 14) (10 10 1) simpleGrading (1 1 1))' \
  system/blockMeshDict
```

Parallel:

```bash
./Allrun parallel
```

Keep the configured `phiERefPoint` off cell faces and processor boundaries so
exactly one rank owns the reference cell.

`postProcessing/2D_<N>_cells.dat` holds the `Vm`/`phiE`/`phiI`/`u1`/`u2`/`u3`
L1/L2/Linf error summary.
